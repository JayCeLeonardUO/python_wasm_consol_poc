CPython 3.14 in the browser, built from source

This is stock CPython 3.14.8 compiled to WebAssembly with Emscripten 4.0.12 using python Platforms/emscripten build. No Pyodide. python.wasm (11 MB) and the stdlib zip (3.8 MB) are served as static files from this repository. Run code runs the editor as a script and exits; Start REPL gives an interactive session. Build notes

print('Welcome to WASM!')
The simple REPL provides a limited Python experience in the browser. Platforms/emscripten/README.md contains a list of known limitations and issues. Networking, subprocesses, and threading are not available.

CPython 3.14.2 + the scientific stack, via Pyodide

Same idea, done by the Pyodide project: CPython 3.14.2 compiled with Emscripten 5.0.3 plus 356 packages cross-compiled for wasm, loaded from jsDelivr when you open this tab (~13 MB, cached). Imports are fetched automatically before a line runs; the first import sklearn pulls ~25 MB (mostly scipy). This is not the self-built binary; see BUILD.md for why sklearn cannot load into it.
